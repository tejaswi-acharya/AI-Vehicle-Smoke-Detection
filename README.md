## Pretrained Model Weights

The pretrained model weights are not included in this repository because of their large file sizes.

Download the required model weights from the link below:

**[Download Pretrained Model Weights](YOUR_GOOGLE_DRIVE_LINK_HERE)**

### Required Files

After downloading, place the files in the following directories:

| File | Destination |
|---|---|
| `ANNPR.weights` | `models/plate_detection/` |
| `Character_saperation.weights` | `models/character_separation/` |
| `model_lenet_200_25.h5` | `models/character_recognition/` |

The corresponding model configuration and architecture files are included in this repository.

### Setup

1. Download the pretrained weights using the link above.
2. Extract the files if they are provided in a ZIP archive.
3. Place each file in its corresponding directory.
4. Follow the installation and usage instructions below.

**Note:** Please ensure that the pretrained weights are used in accordance with their original licensing and usage terms.
